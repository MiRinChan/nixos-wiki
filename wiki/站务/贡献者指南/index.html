如何贡献

  1. Fork并Clone仓库。
  2. 新词条放在entries/{词条名}/index.md。
  3. 子词条放在entries/{父词条}/{子词条}/index.md。
  4. 本地运行npm run build确认可以生成。
  5. 提交pull request。

内容规则

  • 一个词条目录可以没有index.md，但必须有子词条；这种目录页会自动列出直接子词条。
  • 在有子词条的父词条使用{{entries}}模板可列出此父词条的所有子词条。
  • 支持Markdown，也支持HTML；不要提交复杂脚本。
  • 词条资源请放在对应词条目录内。
  • 会被发布的资源类型仅包括：
    • .css
    • .gif
    • .ico
    • .jpeg
    • .jpg
    • .js
    • .png
    • .svg
    • .webp
    • .webm
    • .mp4。
  • 无须在中英文之间添加空格。

模板

位于template/目录的.md文件将视为模板。

{{Thankyou|你的努力|张三}}
{{Thankyou|2=张三|1=你的友谊}}
{{Thankyou|signature=张三|reason=你的一切}}

模板内用三层花括号读取参数：

**感谢你！**
感谢{{{reason|{{{1}}}}}}。
祝好，{{{signature|{{{2}}}}}}敬上。
  • 匿名参数按出现顺序。
  • 编号参数和命名参数使用名称=值。
  • 命名参数的名称和值会去掉首尾空白和换行；匿名参数会保留原样。
  • 空字符串视作已传值，例如{{ParamEcho|bar=}}不会触发{{{bar|fallback}}}的默认值。
  • 默认值可以继续引用参数或模板，例如{{{reason|{{{1}}}}}}。
  • 模板内调用其他模板时不会自动继承外层参数；需要显式传递，例如{{Other|{{{1}}}|name={{{name}}}}}。
  • 缺少模板、非法模板路径、缺少必填参数、模板循环或超过递归深度都会让构建失败。
  • 在 Markdown 的行内代码以及代码块均不展开。

链接

  • 站内词条直接写出就会变成链接。如 [贡献者指南](站务/贡献者指南)。

贡献者协议

通过提交pull request，你同意将你的贡献以CC-BY-SA 4.0许可证授权给本项目。并以附加条件（我管它叫Part CC），令其他人禁止在MediaWiki上使用你的贡献，直到承载维基体承诺优化速度或更换MediaWiki到其他程序。

你需要在提交的pull request末尾加上这是我的翻译或这是我的著作以签署贡献者协议。

前往 GitHub 编辑此页 CC-BY-SA 4.0许可证授权，但禁止在所有 MediaWiki 程序中复制和分发。
