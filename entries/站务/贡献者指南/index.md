## 如何贡献

1. Fork并Clone[仓库](https://github.com/MiRinChan/nixos-wiki)。
2. 新词条放在`entries/{词条名}/index.md`。
3. 子词条放在`entries/{父词条}/{子词条}/index.md`。
4. 本地运行`npm run build`确认可以生成。
5. 提交pull request。

## 内容规则

- 一个词条目录可以没有`index.md`，但必须有子词条；这种目录页会自动列出直接子词条。
- 在有子词条的父词条使用`{{entries}}`模板可列出此父词条的所有子词条。
- 可在根目录`template/`下新建`.md`文件编写可复用模板；例如`template/Thankyou.md`可用`{{Thankyou}}`调用，`template/Foo/Bar.md`可用`{{Foo/Bar}}`调用。
- 首页会列出所有词条和子词条；普通词条页只列出直接子词条。
- 支持Markdown，也支持HTML；不要提交复杂脚本。
- 代码块语言可以写成`语言:文件名`或`语言 文件名`，会显示文件名并高亮。
- 词条资源请放在对应词条目录内。
- 会被发布的资源类型仅包括：`.css`、`.gif`、`.ico`、`.jpeg`、`.jpg`、`.js`、`.png`、`.svg`、`.webp`、`.webm`、`.mp4`。
- 无须在中英文之间添加空格。

## 模板

模板文件只能放在`template/`目录，且必须是`.md`文件。模板会在Markdown渲染前展开，所以模板内容可以继续使用Markdown和HTML。

```markdown
{{Thankyou|你的努力|张三}}
{{Thankyou|2=张三|1=你的友谊}}
{{Thankyou|signature=张三|reason=你的一切}}
```

模板内用三层花括号读取参数：

```markdown
**感谢你！**
感谢{{{reason|{{{1}}}}}}。
祝好，{{{signature|{{{2}}}}}}敬上。
```

- 匿名参数按出现顺序对应`{{{1}}}`、`{{{2}}}`。
- 编号参数和命名参数使用`名称=值`，名称区分大小写。
- 命名参数的名称和值会去掉首尾空白和换行；匿名参数会保留原样。
- 空字符串是已传值，例如`{{ParamEcho|bar=}}`不会触发`{{{bar|fallback}}}`的默认值。
- 默认值可以继续引用参数或模板，例如`{{{reason|{{{1}}}}}}`。
- 模板内调用其他模板时不会自动继承外层参数；需要显式传递，例如`{{Other|{{{1}}}|name={{{name}}}}}`。
- 缺少模板、非法模板路径、缺少必填参数、模板循环或超过递归深度都会让构建失败。

模板在普通正文里会展开，但在用于展示源码的区域会保持原文：

- 行内代码不会展开，例如`` `{{Thankyou|你的努力|张三}}` ``。
- 普通围栏代码块不会展开，例如` ```markdown `开头的代码块。
- 缩进代码块不会展开，例如以四个空格或一个Tab开头的代码行。

## 链接

- 站内词条链接可写相对路径，例如`[贡献者指南](站务/贡献者指南)`。
- 构建后站内词条链接会变成`/wiki/{词条}`。
- 外部链接请写完整URL。

## 贡献者协议

通过提交pull request，你同意将你的贡献以CC-BY-SA 4.0许可证授权给本项目。并以附加条件（我管它叫Part CC），令其他人禁止在MediaWiki上使用你的贡献，直到承载维基体承诺优化速度或更换MediaWiki到其他程序。

你需要在提交的pull request末尾加上`这是我的著作。`以签署贡献者协议。
